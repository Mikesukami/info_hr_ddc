# วิธีติดตั้ง — ทำเพียง 3 ขั้นตอน

## สำหรับการอัปเดตรอบนี้ (โครงสร้างข้อมูลอ้างอิงรุ่น 2)

รอบนี้เปลี่ยน unit_id เป็น org_id เพิ่มต้นไม้หน่วยงานและ country_id **ต้องติดตั้งฐานใหม่ก่อนใช้โค้ดรุ่นนี้** ยังไม่ได้ลบหรือแก้ฐานที่คุณใช้งานอยู่

1. ออกจากระบบก่อน หากต้องการเก็บข้อมูลทดลอง ให้ Export ฐาน study_leave ใน phpMyAdmin ไว้ก่อน
2. ใน phpMyAdmin เลือกเฉพาะฐาน **study_leave** → Operations → Remove database / Drop database → ยืนยัน ตรวจชื่อฐานให้ถูก (ข้อมูลและผู้ใช้เดิมในฐานนี้จะถูกลบ)
3. กลับหน้าแรก phpMyAdmin → Import → เลือก **database/install.sql** ของรุ่นนี้ → Import ไฟล์จะสร้างฐานและ Super Admin ให้ครบ ไม่ต้องรัน GRANT
4. เปิด http://localhost/study%20leave/ เข้าด้วย superadmin และรหัสผ่านเริ่มต้นด้านล่าง แล้วเปลี่ยนรหัสผ่านตามหน้าจอ หากยังเป็น session เดิมให้เปิดหน้าต่างไม่ระบุตัวตน
5. เข้าเมนู **ข้อมูลอ้างอิง** เพื่อเพิ่ม/เปิด/ปิด สำนัก/กอง ประเทศ ประเภทบุคลากร ตำแหน่ง ระดับ และประเภทการบันทึก

หลังรอบนี้ เมื่อมีข้อมูลจริงจะปรับฐานด้วย migration โดยไม่ลบฐานอีก

### วิธีใช้ข้อมูลอ้างอิงใหม่

- Admin และ Super Admin เพิ่ม/เปิด/ปิดได้ เจ้าหน้าที่เข้าหน้าจัดการหรือส่งคำสั่งตรงไม่ได้
- เพิ่มสำนัก/กอง: เลือก “ไม่มีหน่วยงานแม่”; เพิ่มหน่วยงานย่อย: เลือกแม่ รองรับย่อยได้อีก 5 ระดับ
- ชื่อกลุ่มย่อยซ้ำต่างกองได้ แต่ซ้ำภายใต้แม่เดียวกันไม่ได้
- ปิดหน่วยงานแม่ต้องปิดลูกก่อน เปิดลูกต้องเปิดแม่ก่อน
- ฟอร์มลาศึกษา/ฝึกอบรมยังเลือกเฉพาะสำนัก/กอง ไม่แยกตามกฎหมาย/ตามปฏิบัติ และยังบันทึกเป็นรายเรื่อง
- ประเทศเปลี่ยนเป็นรายการให้เลือกเมื่อไปต่างประเทศ ผู้ดูแลเพิ่มประเทศใหม่ได้จากเมนูข้อมูลอ้างอิง
- รายการที่ปิดแล้วไม่แสดงให้เลือกในเรื่องใหม่ แต่ข้อมูลเดิมยังแสดงและคงไว้เมื่อแก้แฟ้มได้

คู่มืออ่านโค้ดและแผนโครงสร้างหน่วยงานอยู่ใน **DEVELOPMENT.md**

## 2. นำเข้า SQL

เปิด http://localhost/phpmyadmin → แท็บ Import → เลือกไฟล์ **database/install.sql** → กด Import

ไฟล์เดียวนี้สร้างฐาน **study_leave**, ตาราง, ข้อมูลอ้างอิง และบัญชี Super Admin ให้ครบ ไม่ต้องรัน GRANT ไม่ต้องใช้คำสั่งติดตั้งอื่น

ใช้กับการติดตั้งใหม่เท่านั้น ถ้ามีฐาน study_leave ที่มีตารางอยู่แล้ว อย่านำเข้าซ้ำหรือเลือกลบทิ้ง ให้สำรองและตรวจฐานเดิมก่อน

## 3. เข้าใช้งาน

เปิด **http://localhost/study%20leave/**

- ชื่อผู้ใช้: **superadmin**
- รหัสผ่านเริ่มต้น: **6ff7a49c996d6d89Aa!**

ระบบจะให้เปลี่ยนรหัสผ่านเมื่อเข้าครั้งแรก หลังเปลี่ยนให้ลบรหัสผ่านเริ่มต้นออกจากคู่มือนี้

Super Admin เป็นผู้ใช้งานในเว็บที่มีสิทธิ์ทุกเมนู อนุมัติผู้สมัคร จัดการทะเบียน และออกลิงก์รีเซ็ตรหัสผ่านได้ ไม่ใช่บัญชีผู้ดูแลฐานข้อมูล

### ถ้า XAMPP ของคุณตั้งรหัสผ่าน MySQL ไว้

แก้เฉพาะไฟล์ **config/local.php** ช่อง password ให้ตรงกับ MySQL ของคุณ ค่าเริ่มต้นเตรียมสำหรับ XAMPP ที่ใช้ root และรหัสผ่านว่าง พอร์ต 3306

หากใช้โฟลเดอร์ชื่ออื่น ให้แก้ base_url ในไฟล์เดียวกันให้ตรงกับ URL ที่เปิด

### เพิ่มผู้ใช้งาน

ให้ผู้ใช้สมัครที่หน้าเข้าสู่ระบบ แล้วเข้า superadmin → ผู้ใช้งานและสิทธิ์ → อนุมัติ เลือกบทบาทเจ้าหน้าที่หรือ Admin

ผู้ลืมรหัสผ่านส่งคำขอได้ที่หน้าเข้าสู่ระบบ Super Admin ตรวจสอบตัวตนแล้วออกลิงก์ใหม่ในหน้าผู้ใช้งาน ลิงก์ใช้ได้ครั้งเดียวภายใน 30 นาที ยังไม่มีการส่งอีเมลอัตโนมัติ

### เมื่อนำไป Windows Server

คัดลอกโฟลเดอร์นี้ทั้งหมด ใช้ Apache/PHP 8.2 พร้อม pdo_mysql, mbstring และ MySQL/MariaDB หากใช้ XAMPP บน Windows Server ทำ 3 ขั้นตอนเดิมได้เลย

สำหรับใช้งานจริง แก้ **config/local.php** ให้เป็นข้อมูลฐานข้อมูลของเซิร์ฟเวอร์และ URL จริงแบบ HTTPS ตั้ง secure_cookies เป็น true ใช้บัญชีฐานข้อมูลที่ผู้ดูแลเซิร์ฟเวอร์ให้แทนค่า root สำหรับทดลอง ไม่ต้องเปลี่ยนบัญชี Super Admin ในเว็บ

ต้องเก็บไฟล์ .htaccess ทุกโฟลเดอร์ และอนุญาตให้ Apache ใช้ไฟล์นี้ (AllowOverride All, mod_rewrite) ให้ PHP เขียน storage/ ได้ ไฟล์ config/local.php และ database/install.sql ต้องเปิดผ่าน URL ไม่ได้

ชุดนี้ใช้ Apache; ถ้าเครื่องปลายทางใช้ IIS ต้องตั้งกฎปิดกั้นไฟล์ของ IIS เพิ่มก่อนใช้งาน

หากย้ายข้อมูลที่ใช้งานแล้ว ให้ Export ฐานเดิมจาก phpMyAdmin แล้ว Import ไฟล์สำรองที่เซิร์ฟเวอร์แทน install.sql เพื่อเก็บผู้ใช้และทะเบียนเดิม

### ไฟล์ในโฟลเดอร์นี้

| รายการ | หน้าที่ |
|---|---|
| index.php | หน้าเริ่มระบบ |
| app/ | ระบบหลังบ้านและหน้าจอ |
| assets/ | รูปแบบหน้าจอ ฟอนต์ และปุ่มเมนู |
| config/local.php | ตั้งค่าฐานข้อมูลและ URL ในไฟล์เดียว |
| database/install.sql | SQL สำหรับติดตั้งใหม่ครบในไฟล์เดียว |
| storage/ | ที่เก็บ session และ log ซึ่งระบบสร้างเอง |
| .htaccess | ป้องกันไฟล์ภายในจากการเปิดผ่านเว็บ |
| README.md | คู่มือนี้ |
| DEVELOPMENT.md | แผนที่โค้ดและคำอธิบายฐานข้อมูลสำหรับผู้เริ่มต้น |
